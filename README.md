# RASCALS - A Top-Down Game

## Welcome to RASCALS!
This is an real-time multiplayer Top-Down game where you play as a cat and chat with other players online.
The game uses WebSockets to synchronize player movement and chat messages between all connected clients.

### Getting started:
- Step 1: Clone this Git Repository
- Step 2: In the terminal write: npm install
- Step 3: To start the server write in the terminal: node server
- Step 4: Now go to your browser and go to: http://localhost:8555/
- Step 5: Choose your username and press the "Start game" -button!

### Once you're in the game:
- You will be assigned a unique cat, either a black, white, orange or gray one depending on what is not already taken. 
- You can then use your "w, a, s, d" -keys to move around. 
- And the chat to the right to talk to other players.
- Whenever you feel like leaving you press the red "Leave game" -button in the top right.

### Have Fun!
